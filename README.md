# view-data-next

대용량 목업 데이터를 만들고, 다양한 차트 렌더링/상호작용/최적화를 연습하는 Next.js 프로젝트입니다.

## 프로젝트 목표

- 목업 데이터 규모별 시각화 연습
- `10,000`건
- `50,000`건
- `100,000`건
- `500,000`건
- `1,000,000`건
- `2,000,000`건
- `5,000,000`건
- `10,000,000`건
- 데이터 양이 커질 때의 렌더링 성능, 메모리 사용량, 인터랙션 반응성 차이 확인
- 차트 구현 방식과 최적화 전략 비교

## 학습 포인트

- 데이터 생성 전략
- 랜덤/시드 기반 데이터 생성
- 시계열/카테고리형 데이터 포맷 설계
- 시각화 구현
- 라인/바/스캐터/영역 차트 등 다양한 형태 실험
- 대용량 처리 최적화
- 집계(aggregation), 샘플링(sampling), 청크 로딩(chunk loading)
- 필요 시 Web Worker 기반 전처리 검토
- 성능 측정
- 초기 렌더 시간
- 필터/줌/호버 등 사용자 인터랙션 지연 시간
- 브라우저 메모리 사용량

## 목업 데이터 사전 생성

앱 실행 전에 스케일/버킷 조합 데이터를 JSON으로 미리 생성할 수 있습니다.

```bash
npm run mockup:generate
```

- 기본 출력 경로: `public/mockup-data`
- 기본 조합: `1만, 5만, 10만, 50만, 100만, 200만, 500만, 1000만` × `40, 80, 120, 160`
- 기본 seed: `20260212`
- 기본 저장 레코드 수: 파일당 `1`건 (`records[0]` 샘플 용도)

옵션 예시:

```bash
npm run mockup:generate -- --seed=20260213 --bucket-counts=80 --keep-records=10
```

## 권장 작업 단계

1. `10,000` ~ `1,000,000`건 정확 생성 비교
2. `2,000,000` ~ `10,000,000`건 샘플 기반 추정 비교
3. 병목 구간 확인 및 최적화 전략 적용
4. 규모별 성능 측정 결과 기록 및 비교

## 데이터 규모별 체크 항목

| 데이터 건수 | 중점 확인 항목 |
| --- | --- |
| 10,000 | 기본 렌더링 정확도, 축/범례/툴팁 동작 |
| 50,000 | 데이터 증가에 따른 렌더 시간 변화 |
| 100,000 | 인터랙션 반응성 저하 여부, 집계 필요성 |
| 500,000 | 생성/전처리 시간과 UI 반응성 균형 |
| 1,000,000 | 직접 렌더 한계, 샘플링/전처리/분할 렌더링 필요성 |
| 2,000,000 | 샘플 기반 집계 결과 안정성과 체감 성능 |
| 5,000,000 | 샘플 확장 시 분포 왜곡 여부, 렌더링 일관성 |
| 10,000,000 | 대규모 시나리오 응답성, UI 상호작용 유지 여부 |

# view-data-next

대용량 목업 데이터를 만들고, 다양한 차트 렌더링/상호작용/최적화를 연습하는 Next.js 프로젝트입니다.

## 프로젝트 목표

- 목업 데이터 규모별 시각화 연습
- `10,000`건
- `100,000`건
- `1,000,000`건
- `10,000,000`건
- `100,000,000`건
- `1,000,000,000`건
- 데이터 양이 커질 때의 렌더링 성능, 메모리 사용량, 인터랙션 반응성 차이 확인
- 차트 구현 방식과 최적화 전략 비교

## 학습 포인트

- 데이터 생성 전략
- 랜덤/시드 기반 데이터 생성
- 시계열/카테고리형 데이터 포맷 설계
- 시각화 구현
- 라인/바/스캐터/영역 차트 등 다양한 형태 실험
- 대용량 처리 최적화
- 집계(aggregation), 샘플링(sampling), 청크 로딩(chunk loading)
- 필요 시 Web Worker 기반 전처리 검토
- 성능 측정
- 초기 렌더 시간
- 필터/줌/호버 등 사용자 인터랙션 지연 시간
- 브라우저 메모리 사용량

## 실행 방법

```bash
npm install
npm run dev
```

- 개발 서버: `http://localhost:3000`

## 현재 기술 스택

- Next.js (App Router)
- React
- TypeScript
- ESLint
- Tailwind CSS
- Apache ECharts (`echarts`, `echarts-for-react`)
- Chart.js (`chart.js`, `react-chartjs-2`)

## 권장 작업 단계

1. `10,000` ~ `1,000,000`건 정확 생성 비교
2. `10,000,000` ~ `1,000,000,000`건 샘플 기반 추정 비교
3. 병목 구간 확인 및 최적화 전략 적용
4. 규모별 성능 측정 결과 기록 및 비교

## 데이터 규모별 체크 항목

| 데이터 건수 | 중점 확인 항목 |
| --- | --- |
| 10,000 | 기본 렌더링 정확도, 축/범례/툴팁 동작 |
| 100,000 | 인터랙션 반응성 저하 여부, 집계 필요성 |
| 1,000,000 | 직접 렌더 한계, 샘플링/전처리/분할 렌더링 필요성 |
| 10,000,000 | 샘플 기반 집계 결과 안정성, 생성 시간 |
| 100,000,000 | 샘플 확장 시 분포 왜곡 여부, 렌더링 일관성 |
| 1,000,000,000 | 초대용량 시나리오 응답성, UI 상호작용 유지 여부 |
